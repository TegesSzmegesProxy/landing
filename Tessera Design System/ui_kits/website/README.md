# Website UI kit
Long-scroll marketing landing for Tessera, built from the brief in `uploads/design.md` (sections A–D) with the bone palette from the user's notes.
- `Header.jsx` — wordmark, NavPill, sign in / deploy
- `Hero.jsx` — headline over the pixel amphitheatre, glass "gate · live" card
- `Flow.jsx` — I–IV numbered steps with a request-path diagram that lights per step
- `PolicySection.jsx` — split copy / live Terminal tail
- `Bento.jsx` — ink section, glass widgets over the night amphitheatre
- `Footer.jsx` — closing CTA + link columns
Interactions: Deploy opens a Dialog; flow steps highlight on hover; terminal and scores tick live.
