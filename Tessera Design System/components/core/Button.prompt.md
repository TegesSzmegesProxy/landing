Pill-shaped action button; one primary per view, everything else secondary/outline/ghost.
```jsx
<Button variant="primary" iconRight="arrow-right">Deploy Tessera</Button>
<Button variant="outline">Read the docs</Button>
```
Variants: primary (blue, ink text), secondary (ink), outline, ghost, bone (over dark or pixel-art imagery), danger (clay). Sizes sm 32 / md 40 / lg 48.
